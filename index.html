Agent Builder Konversation

Sende eine Eingabe an deinen Agenten und lasse die Antwort direkt hier anzeigen. Trage dazu unten deinen OpenAI API-Schlüssel sowie die Agent-ID aus dem Agent Builder ein. Der Aufruf nutzt die offizielle Agents API von api.openai.com; stelle sicher, dass dein Schlüssel über die nötigen Berechtigungen verfügt.

Agent-Konfiguration

Der API-Schlüssel wird nur im Browser genutzt und nicht gespeichert. Um eine neue Unterhaltung zu starten, kannst du die Session-ID leeren oder auf „Session zurücksetzen" klicken.
